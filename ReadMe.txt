Manual to Use this Program: 

Download all dependencies :
- flask
- numpy
- pandas
- opencv-python
- tensorflow
- scikit-learn

How To Run
- Go To NutriScanAI Folder
- Go To Notebooks Folder
- Open app.py on VSC or other IDE and run it
- After you open the server, Upload image you want to use and fill biometric data
- Click analyze and get the result
